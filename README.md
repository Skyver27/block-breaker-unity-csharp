# Block Breaker

A small 2D Block Breaker game built with Unity and C# as part of my game development training.

## Features

- Mouse-controlled paddle movement
- Ball launch and collision handling
- Breakable, multi-hit, and unbreakable bricks
- Three playable levels
- Automatic level progression
- Win and lose states
- Persistent background music
- Optional autoplay mode

## Built With

- Unity
- C#

## What I Practiced

This project helped me practice:

- C# scripting
- Unity scene management
- Game logic and state handling
- Collision detection
- Debugging
- Working with prefabs and game objects

## Project Background

This was created as a learning project while completing the Udemy course **Learn to Code by Making Games – Complete C# Unity Developer**.

I’m keeping it here as part of my early programming portfolio and as a record of my progress into software development.

Some original visual and audio assets are not included in this repository because they were third-party or course assets. The repository focuses on the C# source code I worked with during the project.
